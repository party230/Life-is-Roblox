# Phase 1 mockups (superseded)

These isometric mockups were the first design pass. After the direction change (DECISIONS D20) the game is a
normal 3D Roblox experience, and the playable vertical slice replaces them as the look-and-feel reference.

They're still the reference for the **HUD and screen layouts** (button budget, cash/income/timer, shop and
inspect panel content, eggs screen, base picker). The species shown in `06-concept-*` were replaced by the
character roster in `Config/Species.luau`.
