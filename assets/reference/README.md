# Character reference images

Put one image per character here, named by its id from `src/shared/Config/Species.luau`:

    assets/reference/<id>.png        e.g. assets/reference/tung_tung_tung_sahur.png

Models are matched to these. When a reference is missing, the model is built from the commonly known meme
version, and the character is listed as "built without reference" in LEGAL_REVIEW.md.
